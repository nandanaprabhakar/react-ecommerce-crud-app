# React E-Commerce CRUD Application

A responsive single-page e-commerce application built with React and Vite. The application uses the Fake Store API to display product information and provides CRUD functionality for managing products.

## Features

- Display products from the Fake Store API
- View complete product details
- Add new products
- Edit existing products
- Delete products
- Client-side product state management
- Form validation
- Loading state while fetching products
- Error handling for API failures
- Responsive design for desktop, tablet, and mobile devices

## Technologies Used

- React.js
- Vite
- JavaScript
- Axios
- React Router DOM
- Bootstrap
- Material UI (MUI)
- React Icons
- Google Fonts
- HTML5
- CSS3

## API

This project uses the Fake Store API:

https://fakestoreapi.com/products

Product information is fetched dynamically from the API rather than being hard-coded.
